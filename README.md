# One image for 22 November 2026's world news

Entry for make.fun's [“Sum up 22 November's world news in one image”](https://make.fun/bounty/news-image-20261122) bounty.

The image is a newspaper front page for Sunday 22 November 2026: the COP31
climate talks collapsing in Antalya as the lead story, with the tanker
attacks near Hormuz, NATO bolstering deterrence in Poland, the capture of
“Chapo Isidro” in Mexico, the FBI's police-database probe and the Senate's
permitting bill, BepiColombo's Mercury milestone, and the Seattle airport
arrests — and the day's sport, Alcaraz's first ATP Finals title and
Verstappen's Las Vegas Grand Prix win, in the ticker.

## Run it

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

`main.py` (Python 3, standard library only) copies `entry.png` to the output
directory, which is all this program does.
